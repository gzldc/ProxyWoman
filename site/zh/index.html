免费开源的 Mac 抓包工具

ProxyWoman 可以抓取、解密、查看、Mock 和改写 Mac App、浏览器、iPhone、安卓手机和 iOS 模拟器的网络流量。Swift 原生开发，永久免费，无需账号，无数据上报。

下载 macOS 版 GitHub 源码

macOS 14 及以上 · Apple 芯片和 Intel · Apache-2.0 · 版本 0.1.3

功能

HTTPS、HTTP/2、WebSocket

用本机生成的根证书解密 HTTPS。支持 HTTP/1.1、HTTP/2 和 WebSocket 消息，按 App 和域名归类。

规则、Map Local、Map Remote

不限数量的规则：按字段设置条件，按顺序执行动作。改写请求头、内容、URL、状态码，返回 Mock 响应或本地文件，延迟或断开请求。

断点

在请求发出前或响应返回前暂停，编辑后放行或中止。

Compose 与重复发送

新建或编辑请求并发送，可按次数、并发和间隔重复发送。

HAR 导入导出

把会话保存为 HAR 并重新打开；可打开 Chrome、Safari、Firefox、Charles、Proxyman 导出的 HAR。任意请求可复制为 cURL。

JWT 解析

自动解码请求头、Cookie 和 URL 中的 JWT，显示签发和过期时间。

iPhone、安卓、iOS 模拟器

手机扫码配置，并提供证书下载页；一键把证书装进所有正在运行的 iOS 模拟器。

安全的系统代理

一键开关 macOS 系统代理，崩溃后也能恢复原设置，可串联 Clash 等已有代理。

给 AI 用的 MCP 服务

Claude、Cursor 等 MCP 客户端可以读取和分析抓到的流量，敏感信息默认脱敏。

中英文界面

完整的简体中文和英文界面，可在 App 内切换。

快速上手

  1. 下载适合你 Mac 的 DMG（Apple 芯片选 -arm，Intel 选 -intel），把 ProxyWoman 拖到“应用程序”。
  2. App 暂未经过 Apple 公证：首次打开请到 系统设置 ▸ 隐私与安全性 ▸ 仍要打开。
  3. 选择 证书 ▸ 在这台 Mac 上安装证书…，即可查看 HTTPS 内容。
  4. 打开工具栏上的 系统代理，然后使用你的 App 或浏览器。

常见问题

ProxyWoman 免费吗？
免费。基于 Apache License 2.0，所有功能对个人和商业使用都免费，没有付费版、试用期、账号和统计上报。
Mac 上有什么免费的 Proxyman / Charles 替代品？
ProxyWoman：HTTPS 解密、不限数量的规则、Map Local、Map Remote、断点、Compose、HAR 导入导出、手机和 iOS 模拟器抓包、MCP 服务，全部免费开源。
它和 Wireshark 有什么区别？
Wireshark 抓原始网络包，没有会话密钥时 HTTPS 仍是加密的。ProxyWoman 工作在 HTTP 层，作为代理解密 HTTPS，并能修改请求和响应。
Mac 上怎么抓 iPhone / 安卓手机的 HTTPS？
打开 允许局域网设备连接，把手机 Wi-Fi 代理设为界面上显示的地址，然后用手机浏览器打开 http://proxywoman.cert 或扫码下载证书，安装并信任。
能抓 iOS 模拟器的流量吗？
能。启动模拟器，选择 证书 ▸ 安装到 iOS 模拟器，再打开 系统代理。
开着 Clash 抓包会断网吗？
不会。ProxyWoman 会串联 Clash 等已有代理，关闭或退出时自动恢复原设置，即使崩溃后也能恢复。
会上传我的流量吗？
不会。抓到的会话只保存在你的 Mac 上。
